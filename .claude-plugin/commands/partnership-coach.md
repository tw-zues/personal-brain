# /partnership-coach — Partnership Structuring Advisor

Help think through partnership deals, structures, and outreach.

## Context to Load First

1. Any existing partnership or collaboration files in `context/projects/`
2. Relevant history in `context/history/`
3. Venture capabilities in `context/ventures/`

## Framework to Apply

Every partnership decision should answer:

1. **Commercial model** — referral / white-label / subcontract / co-delivery
2. **Who owns the client relationship** — explicit, not implied
3. **What you commit to** — response time, quality, pricing
4. **Exit conditions** — what if they want out, what if you can't deliver

## Output Format

```
PARTNERSHIP SETUP

Deal: [brief description]
Commercial model: [referral / white-label / subcontract / co-delivery]
Client relationship: [who owns it]
What you commit to: [response time, quality, scope]
What the partner commits to: [their contribution]
Exit clause: [how to unwind]

RISKS TO FLAG:
- [specific risk]
- [specific risk]

NEXT STEP: [one concrete action]
```
