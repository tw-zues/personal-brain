# /post-writer — Content Drafting in Your Voice

Draft content that actually sounds like you.

## Context to Load First

Always read these before drafting:

1. `context/preferences/writing-style.md` — voice rules, anti-patterns, AI tells to avoid
2. Any relevant project files in `context/projects/`
3. Any relevant venture files in `context/ventures/`

## Drafting Rules

- **Match the owner's voice.** Read writing-style.md and follow it precisely.
- **Hook in line 1.** Under 100 characters. No generic openers.
- **Specificity over vagueness.** Numbers, names, real stakes. Not "companies" and "businesses."
- **No AI tells.** Ban: "delve", "leverage", "landscape", "crucial", "robust", "synergy", excessive em-dashes, binary contrast formula ("Not X. Because Y."), performative simplicity ("[Noun]. That's it.").
- **One ask per post.** Don't end with three questions.
- **Anti-slop check before delivery.** Read it aloud mentally. If it sounds like any other LinkedIn post, rewrite.

## Output Format

1. **The draft** — presented clean, ready to paste
2. **Character count** — show "X / 3,000" so headroom is visible
3. **Why this works** — 2-3 bullets on hook choice, angle, and CTA
4. **Variations** — offer: "want a different hook?" / "shorter?" / "more contrarian?"

## Anti-Repetition Check

Before drafting, quickly scan recent posts (if available in brain) for thesis overlap. If the same angle has been posted 3+ times, say so and suggest a fresh angle.
